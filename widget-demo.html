Embed code

One iframe. Nothing else required.

Copy this code into the HTML of your website. The widget stays hosted by ReIndexMe, so future compatible updates can be delivered without replacing the embed.

Recommended iframe embed 
<iframe
  src="https://reindexme-widget.vercel.app/"
  width="480"
  height="420"
  title="ReIndexMe LinkedIn Refresh widget"
  loading="lazy"
  style="border:0;width:100%;max-width:480px;overflow:hidden;"
></iframe>

Why iframe?

The iframe is the simplest and most predictable way to embed the current widget.

  • No JavaScript integration required.
  • No ReIndexMe account required.
  • Responsive up to 480 px.
  • The widget remains isolated from your page styles.
What it includes

A smaller version of LinkedIn Refresh.

The widget does not simulate automatic submissions. It gives users useful, transparent actions.

01

Profile check

Validates a public LinkedIn profile URL and lets the user open the profile directly.

02

Google visibility

Builds an exact-profile search so the user can inspect the result currently shown by Google.

03

Bing visibility

Provides the equivalent search path on Bing for comparison.

04

Google diagnostics

Opens an official Google diagnostic tool without claiming that it forces indexing.

05

No fake submissions

The interface explicitly tells users when no indexing request has been sent.

06

Lightweight embed

No account, no setup wizard and no integration with your own backend.

Privacy model

No profiling relationship required.

ReIndexMe Widget 2.0 is not designed to create user accounts or store a history of LinkedIn URLs entered through the widget. External links such as Google, Bing and LinkedIn are opened in the user's browser and are governed by those services' own terms and privacy policies.
